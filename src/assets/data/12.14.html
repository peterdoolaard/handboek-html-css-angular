Dit is een voorbeeld van een thema met een lichte en een donkere variant.

Werkt zonder JavaScript

De schakelaar voor het lichte of donker thema is een label met een checkbox als child. Als de checkbox is ingeschakeld, geldt color-scheme: dark. En bij een uitgeschakelde checkbox geldt color-scheme: light.

Checkbox zonder opmaak

Met appearance: none is de checkbox van zijn opmaak verlost. Daardoor is de checkbox altijd visueel verborgen, terwijl de functionaliteit behouden blijft.

Focus-visible voor zichtbare focus

Het uitschakelen van focus-visible op de input moet wel worden hersteld voor fatsoenlijke toetsenbordnavigatie. Daarvoor zorgt de selector label:has(input:focus-visible). Deze zet een outline op het label als de input met het toetsenbord focus krijgt.
